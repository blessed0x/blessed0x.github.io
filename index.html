// arsenal

Open-source tools, in pure Go and shell.

xkvm-ios-injector

Go

Inject tweaks & dylibs into IPA files — a pure-Go rewrite of the cyan/pyzule-rw bloodline. Sideload injected apps, extract tweaks back out, and convert between jailbreak package layouts. Byte-faithful to upstream tools, no Python required.

macos-debloater

Shell

Debloat macOS — disable the services you don't use. Mode 1–4, TUI, enterprise config, or manual pick. Trim launchd agents, cut background noise, and take back RAM without touching what you actually need.

scratch-unified-mcp

The first standalone headless Scratch VM over MCP — 108 tools for AI agents to build, playtest, and publish Scratch projects. Turbowarp-powered, no browser needed, fully scriptable.
